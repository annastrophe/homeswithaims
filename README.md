# Homes with AIMS — Landing page

Landing page for Andik Imran & Mirta Syazanna (PropNex), Punggol & Sengkang specialists.

## Files
- `index.html` — the page
- `support.js`, `image-slot.js` — runtime scripts (keep next to index.html)
- `.image-slots.state.json` — your uploaded photos (keep next to index.html)
- `.nojekyll` — lets GitHub Pages serve the photo file above

## Publish on GitHub Pages
1. Create a repo and upload **all** files in this folder (including the dot-files).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root → Save.
3. Your site will be live at `https://<username>.github.io/<repo>/`.
